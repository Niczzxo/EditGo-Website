# EditGo Website

The official website for [EditGo](https://github.com/Niczzxo/EditGo) — a video editor for Android, inspired by the Instagram Edits workflow.

Live site: deployed on Vercel from this repo.

## What's here

- `index.html` — the whole site: hero, download button, features, install steps.
- Download button links to the EditGo v0.1.0 APK on the GitHub release:
  https://github.com/Niczzxo/EditGo/releases/download/v0.1.0/EditGo-v0.1.0-debug.apk

## Deploy

Static site, no build step. Import this repo in Vercel as a static project and deploy.
